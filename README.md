# HEIA NA Equity: Bloomberg P&L Financial Analysis

Extraction, cleaning and analysis of Bloomberg P&L data for HEIA NA Equity (FY2017-FY2024).

## Objective
- Extract and clean raw Bloomberg P&L data using Python
- Standardise line items and regions into analysis-ready tables
- Build an Excel P&L model and Power BI dashboard
- Summarise revenue, profit and margin trends for the CFO

## Tools Used
- Python (Jupyter): data cleaning and transformation
- Excel: P&L model
- Power BI: interactive dashboard
- Bloomberg data extract (synthetic)

## Project Files
| File | Description |
|------|-------------|
| HEIA_NA_Equity python notebook.html | Data cleaning and analysis notebook |
| HEIA_PL_Model.xlsx | Excel P&L model |

| HEIA_NA_Equity_Bloomberg_Extract_SYNTHETIC.xlsx | Input data |
| Bloomberg_PL_Data_Extraction_Project_Brief_HEIA.pdf | Project brief |

## Key Findings
- Revenue trend across FY2017-FY2024 is analysed by region and line item in the dashboard
- Profit and margin movements are tracked year-wise in the Excel P&L model
- Detailed insights and recommendations for the CFO are in the project report
